onepager

Turn public company information into a beautifully designed, investor-ready one-pager PDF. One JSON profile in, a polished A4 document out — in your choice of three templates.

Three templates

Each rendered from the same profile — pick the personality that fits the company.

boardroom

Structured two-column corporate layout with a dark stats panel and an investment-highlights grid.

horizon

Hero-image layout with centered branding, icon feature cards, and a share-information table.

summit

Modern full-height brand sidebar with large display type and stacked key statistics.

How it works

Everything an investor needs, captured once.

1 · Collect

Pull the company's public information — description, tickers, share structure, projects, highlights, team, news — into one JSON profile.

2 · Brand

Add the logo and brand colors, or let the tool extract the dominant color from the logo automatically.

3 · Generate

Render any of the three templates to a print-ready A4 PDF from the CLI or the built-in web UI.

Run it

The PDF engine (WeasyPrint) needs a Python host, so generation runs locally or on your own server.

# install
git clone https://github.com/coltongriffith/one-pager && cd one-pager
pip install -e ".[web]"

# browser UI at http://localhost:8000
onepager serve

# or straight from the command line
onepager init my-company.json
onepager build my-company.json --all -o output/

# or run the web UI with Docker
docker build -t onepager . && docker run -p 8000:8000 onepager
Why isn't the generator on this page? This site is a static landing page. PDF rendering depends on native libraries (Pango/Cairo) that serverless static hosts don't provide — deploy the Docker image to any container host (Render, Railway, Fly.io, your own box) to put the web UI online.
